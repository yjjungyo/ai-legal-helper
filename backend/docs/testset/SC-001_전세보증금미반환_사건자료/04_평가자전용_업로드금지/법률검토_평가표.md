# 법률 분석 평가표 (전문가 검증 전 잠정 기준)

## 법률 참조항목
- 주택임대차보호법 제3조: 대항력 취득 요건과 시점
- 주택임대차보호법 제3조의2: 확정일자 우선변제권 및 관련 조건
- 주택임대차보호법 제3조의3: 임차권등기명령 요건과 효력
- 주택임대차보호법 제3조의5: 경매에 의한 임차권 소멸의 예외
- 주택임대차보호법 제6조, 제6조의2: 갱신 및 해지 통지 효과
- 민법상 임대차 종료 시 인도와 보증금 반환의 동시이행 문제

## 확인할 공식 출처
- 국가법령정보센터 주택임대차보호법: https://www.law.go.kr/법령/주택임대차보호법
- 국가법령정보센터 민법: https://www.law.go.kr/법령/민법
- 판례 검색: https://www.scourt.go.kr/supreme/decisions/decision.jsp

법령 원문과 적용 시점의 규정, 판례의 사실관계는 평가 전에 검증해야 한다. 판례번호는 확인되지 않았으므로 임의 기재하지 않는다.

## 평가 원칙
1. 법률 결론의 단정이 아니라 요건 검토와 부족한 근거 식별을 평가한다.
2. 가압류 vs 근저당의 구별을 검사한다.
3. 입주, 전입, 확정일자의 상이한 날짜를 혼동하지 않는지 확인한다.
4. 9월 30일의 의미를 통지·합의 여부와 분리한다.
5. 낙찰자 인수 및 배당액을 등기부·선순위 권리 확인 없이 확정하는 경우 감점한다.
6. 보증기관 가입 여부를 추측하지 않는지 평가한다.
