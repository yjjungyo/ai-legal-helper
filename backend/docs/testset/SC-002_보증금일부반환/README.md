# E2E-LEASE-02 — 사용 방법

이 패키지는 AI Legal Helper의 독립 사건 검증을 위한 합성 테스트 데이터입니다. 실제 계약, 금융거래 또는 법원 사건을 나타내지 않습니다. 

1. `E2E_LEASE_02_SCENARIO.md`를 읽고 **새 사건**을 생성합니다. 기존 SC-001/Gold v1.2는 변경하지 않습니다.
2. `evidence/`의 파일을 시나리오 단계 A~H에 따라 업로드합니다. 실제 제품의 증거 검토·승인 과정을 이용합니다.
3. `consultation_turns.json`의 질문을 **동일 Conversation**에서 1~10번 순서로 입력합니다.
4. 단계별 기대 결과는 `expected_outcomes.json`에서 확인합니다.
5. `E2E_LEASE_02_SCENARIO.md`의 불합격 기준 및 법률적 단서를 반드시 적용합니다.

원본 evidence/ 문서 본문에는 사용자에게 보이는 테스트 상태 문구를 넣지 않았습니다. 증거 파일은 plain-text 전사이며 별도 진위 확인된 공문서/은행 원본이 아니므로 시스템 검증 단계에서는 정책에 따른 사람 검토 또는 확정 전 단계가 필요할 수 있습니다.
