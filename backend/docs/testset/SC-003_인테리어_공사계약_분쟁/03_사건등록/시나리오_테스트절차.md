# SC-002 테스트 시나리오 — 인테리어 공사 분쟁

## 목적
여러 증거에서 계약·지급·중단·시정최고·손해를 연결하고 당사자 간 상충 주장 및 부족한 입증을 탐지한다.

## 사건 설정
- 발주자: 김서윤 / 수급인: 한빛인테리어
- 계약: 8,000만 원, 지급액: 6,000만 원
- 추가공사비 1,500만 원 승인 여부 다툼
- 6월 16일 중단, 당초 준공 6월 30일
- 시공업체 공정률 85%, 발주자 측 점검 65%
- 발주자는 계약해제, 대체공사비 및 영업손실 주장

## 평가 단계
1. S1: E01,E02,E14 입력 → 계약·지급액·미확인정보 정리
2. S2: E03,E04,E05,E16,E18 추가 → 추가공사 승인 다툼 및 통화·문자 충돌 분석
3. S3: E06,E07,E09,E17 추가 → 공정률 충돌 및 작업중단의 귀책 검토
4. S4: E08,E10,E11,E12,E13,E15 추가 → 해제·정산·하자·손해 종합

## 과제 목록
- T01 계약·당사자·금액 추출
- T02 지급 총액 및 정산 항목 확인
- T03 사건 타임라인·행위 연결
- T04 공정률 65% 대 85% 주장 출처 비교
- T05 추가공사 합의 형성 여부에 관한 찬반 증거 비교
- T06 중단 사유·계약해제·시정최고의 조건 검토
- T07 하자, 대체공사비, 영업손실의 증명 필요사항
- T08 추가 확보 증거와 우선 대응 조치

## 공정한 A/B/C 비교 원칙
A와 B에 동일한 증거 원문 TXT를 제공한다. C는 동일한 증거 PDF를 등록한다. 질문은 동일한 문자열을 사용한다. 데이터셋과 모델 버전을 고정한다. 사전 처리 비용과 질의 비용을 별도로 측정한다. 정답지와 이 문서는 C를 포함한 분석시스템 입력에 제공하지 않는다.

## 중요 한계
음성 원본 없이 작성된 통화 녹취록은 발언 사실을 독립적으로 입증하지 않는다. 내용증명 도달·추가공사 실제 합의·공정률·영업손실은 미확정 사항으로 둔다.
