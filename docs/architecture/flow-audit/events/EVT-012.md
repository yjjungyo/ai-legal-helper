```mermaid
sequenceDiagram

    participant User as User

    participant PostgreSQL as PostgreSQL (:5432)

    participant Langfuse as Langfuse (:3001)

    User->>React: 질문 입력창에 법률 질문 작성 후 '🚀 상담 요청하기' 클릭

    FastAPI->>Langfuse: create_trace(name="api_request", path="/api/v1/consultations")
    FastAPI->>PostgreSQL: SELECT * FROM cases WHERE id = :case_id
    alt 사건이 존재하나 현재 사용자 소유가 아님
        FastAPI-->>React: HTTP 403 Forbidden {"detail": "이 사건에 대한 접근 권한이 없습니다."}
    else 접근 권한 확인 완료
        FastAPI->>Mem: _consultations[request_id] = ConsultationResponse(status="IN_PROGRESS")
        FastAPI->>PostgreSQL: INSERT INTO consultations (id=request_id, case_id, question, status='IN_PROGRESS')
        FastAPI->>BG: background_tasks.add_task(process_consultation, request_id, question, case_id)
        FastAPI-->>React: HTTP 200 OK {request_id, status: "IN_PROGRESS", question}
        React->>React: setResult(initialRes), setInterval(2000ms) 폴링 시작

        loop 2초마다 폴링 (status !== 'IN_PROGRESS' 될 때까지)
            React->>FastAPI: GET /api/v1/consultations/{request_id}
            FastAPI->>Mem: _consultations.get(request_id) 조회 (없으면 PostgreSQL consultations 조회)
            Mem-->>FastAPI: ConsultationResponse 반환
            FastAPI-->>React: HTTP 200 OK {status: "IN_PROGRESS" | "COMPLETED" | "ERROR", ...}
            alt status == "COMPLETED" 또는 "ERROR"
                React->>React: clearInterval(pollInterval), setResult(currentStatus), setLoading(false)
                React->>React: onComplete() -> loadHistory() (GET /api/v1/cases/{case_id}/consultations)
                React-->>User: 상담 완료 답변 또는 에러 메시지 표시
            end
        end
    end
```
