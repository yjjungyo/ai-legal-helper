## 2. End-to-End Sequence Diagram

```mermaid
sequenceDiagram
    autonumber
    participant OS as OS / Uvicorn
    participant FastAPI as FastAPI (api/main.py:lifespan)
    participant Worker as graph_sync_worker_loop
    participant Neo4jMod as database/neo4j.py
    participant LFClient as observability/langfuse_client.py
    participant Engine as database/session.py (SQLAlchemy Engine)

    OS->>FastAPI: SIGINT / SIGTERM 종료 시그널 수신 (lifespan yield 이후 진입)
    FastAPI->>Worker: sync_worker_task.cancel()
    Worker->>Worker: except asyncio.CancelledError -> logger.info("종료 신호 수신, 루프 중단")
    FastAPI->>Neo4jMod: close_neo4j_driver()
    Neo4jMod->>Neo4jMod: _driver.close(), _driver = None ("Neo4j 드라이버 연결 종료")

    Note over FastAPI,Engine: ⚠️ 누락된 종료 정리 작업
    FastAPI-xLFClient: flush_langfuse() 미호출! (버퍼에 남은 마지막 Trace 유실 가능)
    FastAPI-xEngine: engine.dispose() 미호출! (프로세스 종료 시 OS가 소켓 회수)
    FastAPI-->>OS: ASGI lifespan shutdown 완료
```
