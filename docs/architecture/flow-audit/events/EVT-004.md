## 2. End-to-End Sequence Diagram

```mermaid
sequenceDiagram
    autonumber
    participant User as User
    participant React as React (CaseList.tsx)

    participant Langfuse as Langfuse (:3001)

    User->>React: 메인 경로('/') 진입
    React->>React: useEffect -> loadCases() (loading = true)
    React->>FastAPI: GET /api/v1/cases
    FastAPI->>Langfuse: create_trace(name="api_request", path="/api/v1/cases")
    FastAPI->>FastAPI: Depends(get_current_user)
    FastAPI->>PostgreSQL: SELECT * FROM cases WHERE user_id = :uid ORDER BY created_at DESC
    alt 조회 성공
        PostgreSQL-->>FastAPI: List[Case] 반환
        FastAPI-->>React: HTTP 200 OK List[CaseSchema] JSON
        React->>React: setCases(data), setLoading(false)
        alt 사건이 1건 이상 존재
            React-->>User: 사건 카드 그리드 (제목, 사건유형 배지, 상태 배지, 생성일, 삭제 버튼) 렌더링

        end
    else API/DB 오류
        FastAPI-->>React: HTTP 500
        React->>React: setError("사건 목록을 불러오는데 실패했습니다."), setLoading(false)
        React-->>User: 에러 배너 및 '다시 시도' 버튼 렌더링
    end
```
