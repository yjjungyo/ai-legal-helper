```mermaid
sequenceDiagram
    autonumber
    participant User as User
    participant React as React (CaseWorkspace.tsx)
    participant FastAPI as FastAPI (cases.py / dependencies.py)

    User->>React: 사건 카드 클릭 (/:caseId/workspace/* 진입)

    FastAPI->>Langfuse: create_trace(name="api_request", case_id=case_id)

    alt 사건 없음 (404) 또는 타 사용자 소유 사건 (403)
        PostgreSQL-->>FastAPI: None 또는 user_id 불일치
        FastAPI-->>React: HTTP 404 Not Found 또는 HTTP 403 Forbidden
        React->>React: alert("사건을 불러올 수 없습니다.") -> navigate("/")

        FastAPI->>PostgreSQL: ORM Relationship Lazy Load (parties, facts, events, legal_issues)
        PostgreSQL-->>FastAPI: Case + 하위 컬렉션 반환
        FastAPI-->>React: HTTP 200 OK CaseDetailSchema JSON
        React->>React: setActiveCase(data), setLoading(false)
        React-->>User: 좌측 사이드바(사건명, 유형, 카운트 배지) 및 활성 탭 화면 렌더링
    end
```
