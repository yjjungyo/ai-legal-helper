```mermaid
sequenceDiagram
    autonumber

    participant React as React (EvidenceSection / ReviewModal)
    participant FastAPI as FastAPI (routes/evidence.py:265)

    alt 1) '✓ 승인 (Fact 등록)' 클릭
        User->>React: Claim 카드에서 '✓ 승인 (Fact 등록)' 클릭 -> handleApprove(claim)
        React->>FastAPI: POST .../claims/{claim_id}/review {action: "APPROVE"}
    else 2) '✎ 수정 승인' 클릭
        User->>React: '✎ 수정 승인' 클릭 -> ReviewModal에서 문장(new_statement) 및 사유 입력 후 '수정 후 Fact 등록' 클릭
        React->>FastAPI: POST .../claims/{claim_id}/review {action: "EDIT", new_statement, review_reason}
    else 3) '✕ 반려' 클릭
        User->>React: '✕ 반려' 클릭 -> ReviewModal에서 반려 사유 입력 후 '반려 확정' 클릭
        React->>FastAPI: POST .../claims/{claim_id}/review {action: "REJECT", review_reason}
    end

    FastAPI->>Langfuse: create_trace(name="api_request", case_id=case_id)
    FastAPI->>FastAPI: Depends(verify_case_ownership) 및 문서 소속 검증

    alt action == "APPROVE" 또는 "EDIT"
        FastAPI->>Service: promote_claim_to_fact(db, claim_id, action, new_statement, review_reason)
        Service->>PostgreSQL: SELECT EvidenceClaim WHERE id = :claim_id
        Service->>PostgreSQL: UPDATE evidence_claims SET review_status = ('APPROVED' | 'EDITED'), statement = (new_statement), reviewed_at = now()
        Service->>PostgreSQL: SELECT Fact WHERE case_id = :cid AND description = :final_statement (중복 검사)
        alt 동일 문장의 Fact가 없는 경우
            Service->>PostgreSQL: INSERT INTO facts (case_id, description, category, confidence, status='verified', source='evidence_promoted')
        end
        Service->>PostgreSQL: INSERT INTO evidence_links (case_id, claim_id, target_type='FACT', target_id=fact.id, link_type='SUPPORTS')
        Service->>PostgreSQL: db.commit()
    else action == "REJECT"
        FastAPI->>Service: reject_claim(db, claim_id, review_reason)
        Service->>PostgreSQL: UPDATE evidence_claims SET review_status = 'REJECTED', review_reason = :reason, reviewed_at = now()
        Service->>PostgreSQL: db.commit()
    end

    FastAPI->>PostgreSQL: queue_sync_task(db, case_id) & db.commit()
    FastAPI->>PostgreSQL: SELECT EvidenceSpan (span_text, span_page 보강)

    React->>React: loadClaims(selectedDocId), loadConflicts(), onEvidenceUpdated() (-> loadCase(caseId))
```

   - `graph_sync_tasks`에 동기화 태스크 `INSERT` 및 `db.commit()`.

8. **외부 LLM·도구 호출**: 없음.
9. **응답 JSON 구조**: 갱신된 `EvidenceClaimResponse` JSON.
10. **프런트엔드 상태 변경**: `claims` 배열 갱신, `ReviewModal` 닫기, 부모 `CaseWorkspace`의 `loadCase(caseId)` 호출로 `activeCase.facts` 즉시 갱신.

12. **Langfuse 기록**: `api_request` Root Trace 기록.
13. **실패·예외 처리 경로**:

    - `EDIT` 액션인데 `new_statement`가 비어 있으면 **HTTP 400**을 반환한다.
