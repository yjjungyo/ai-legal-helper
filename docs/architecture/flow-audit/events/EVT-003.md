## 2. End-to-End Sequence Diagram

```mermaid
sequenceDiagram
    autonumber
    participant User as User
    participant React as React (CaseList / CreateCaseModal)
    participant FastAPI as FastAPI (routes/cases.py)
    participant Service as CaseMemoryManager (manager.py)
    participant PostgreSQL as PostgreSQL (:5432)
    participant Langfuse as Langfuse (:3001)

    User->>React: '+ 새 사건 등록' 버튼 클릭 -> 모달에 제목(title) 및 사건 유형(caseType) 입력 후 '사건 생성' 클릭
    React->>React: handleSubmit() -> title.trim() 검증, isSubmitting = true
    React->>FastAPI: POST /api/v1/cases {title, case_type}
    FastAPI->>Langfuse: create_trace(name="api_request", path="/api/v1/cases")
    FastAPI->>FastAPI: Depends(get_current_user)로 current_user 식별
    FastAPI->>Service: CaseMemoryManager(db).create_case(title, case_type, description, user_id)
    Service->>PostgreSQL: INSERT INTO cases (id=uuid4(), user_id, title, case_type, status='OPEN', version=1)
    alt INSERT 성공
        PostgreSQL-->>Service: Commit 완료 및 new_case refresh
        Service-->>FastAPI: Case ORM 객체 반환
        FastAPI-->>React: HTTP 200 OK CaseSchema JSON
        React->>React: onCreated(newCase.id) -> navigate(`/${newCaseId}/workspace/overview`)
        React-->>User: 생성된 사건의 워크스페이스 화면으로 즉시 이동 (EVT-005, EVT-035 연쇄 발생)
    else DB 오류 또는 유효성 실패
        PostgreSQL-->>Service: Exception -> db.rollback()
        FastAPI-->>React: HTTP 422 / HTTP 500
        React-->>User: 모달 내 빨간색 에러 배너("사건 생성에 실패했습니다.") 출력
    end
```
