## 2. End-to-End Sequence Diagram (회원가입 422 버그 및 로그인 상태 버그 포함)

```mermaid
sequenceDiagram
    autonumber
    participant User as User
    participant React as React (Register / Login / AuthContext)
    participant FastAPI as FastAPI (routes/auth.py)
    participant PostgreSQL as PostgreSQL (:5432)
    participant Langfuse as Langfuse (:3001)

    Note over User,PostgreSQL: [A] 회원가입 플로우 (Register.tsx -> POST /api/v1/auth/register)
    User->>React: /register 화면에서 이름(name), 이메일(email), 비밀번호(password) 입력 후 '가입하기' 클릭
    React->>FastAPI: POST /api/v1/auth/register {"email": email, "password": password, "name": name}
    FastAPI->>Langfuse: create_trace(name="api_request", path="/api/v1/auth/register")
    Note over FastAPI: ❌ 계약 불일치 버그 (auth.py:18 vs authClient.ts:24)<br/>백엔드 UserCreate 스키마는 'display_name: str'을 필수로 요구하지만<br/>프런트엔드는 'name' 키를 전송함!
    FastAPI-->>React: HTTP 422 Unprocessable Entity (Field required: display_name)
    React-->>User: 에러 배너 출력 (회원가입 실패)

    Note over User,PostgreSQL: [B] 로그인 플로우 (Login.tsx -> POST /api/v1/auth/login)
    User->>React: /login 화면에서 이메일, 비밀번호 입력 후 '로그인' 클릭
    React->>FastAPI: POST /api/v1/auth/login {"email": email, "password": password}
    FastAPI->>PostgreSQL: SELECT * FROM users WHERE email = :email
    FastAPI->>FastAPI: bcrypt.checkpw(password, user.password_hash) 검증
    alt 이메일 없음 또는 비밀번호 불일치
        FastAPI-->>React: HTTP 401 Unauthorized {"detail": "이메일 또는 비밀번호가 올바르지 않습니다."}
    else 인증 성공
        FastAPI->>FastAPI: raw_token = secrets.token_urlsafe(32), token_hash = sha256(raw_token)
        FastAPI->>PostgreSQL: INSERT INTO user_sessions (user_id, token_hash, expires_at=now+7days)
        FastAPI-->>React: HTTP 200 OK {"message": "로그인 성공"} + Set-Cookie: session_token=... (HttpOnly)
        Note over React: ⚠️ 프런트 상태 버그 (AuthContext.tsx:41)<br/>const userData = await apiLogin(email, password);<br/>setUser(userData); -> user 상태가 {"message": "로그인 성공"}이 됨!
        React->>React: navigate('/')
    end

    Note over User,PostgreSQL: [C] 로그아웃 플로우 (Navbar -> POST /api/v1/auth/logout)
    User->>React: 상단 Navbar '로그아웃' 버튼 클릭
    React->>FastAPI: POST /api/v1/auth/logout (Cookie: session_token)
    FastAPI->>PostgreSQL: DELETE FROM user_sessions WHERE token_hash = sha256(session_token)
    FastAPI-->>React: HTTP 200 OK {"message": "로그아웃 성공"} + Delete-Cookie: session_token
    React->>React: setUser(null) -> navigate('/login')
```

## 3. 13단계 실행 경로 상세 추적

1. **이벤트 발생 화면 및 컴포넌트**: [`Register.tsx`](file:///c:/myprjs/ai-legal-helper/frontend/src/pages/Register.tsx), [`Login.tsx`](file:///c:/myprjs/ai-legal-helper/frontend/src/pages/Login.tsx), [`App.tsx`](file:///c:/myprjs/ai-legal-helper/frontend/src/App.tsx) `Navbar`.

3. **호출되는 API와 HTTP Method**:
   - `POST /api/v1/auth/register`
   - `POST /api/v1/auth/login`
   - `POST /api/v1/auth/logout`
4. **FastAPI Router**: [`api/routes/auth.py:42-127`](file:///c:/myprjs/ai-legal-helper/backend/src/ai_legal_helper/api/routes/auth.py#L42-L127).
5. **Service / Repository 함수**: `get_password_hash()`(`bcrypt.hashpw`), `verify_password()`(`bcrypt.checkpw`), `hash_token()`(`hashlib.sha256`).
6. **DB 읽기·쓰기**:
   - 회원가입(정상 스키마 호출 시): `users` 테이블 `INSERT`.
   - 로그인: `users` 조회 및 `user_sessions` 테이블 `INSERT` (유효기간 7일).
   - 로그아웃: `user_sessions` 테이블에서 `token_hash` 일치 행 `DELETE`.
7. **AI Agent 또는 RAG 호출**: 없음.
8. **외부 LLM·도구 호출**: 없음.
9. **응답 JSON 구조**:
   - `/auth/register` (성공 시 201): `{"id": "...", "email": "...", "display_name": "...", "status": "ACTIVE"}`
   - `/auth/login` (200): `{"message": "로그인 성공"}` + `Set-Cookie: session_token=...; HttpOnly; SameSite=lax`
   - `/auth/logout` (200): `{"message": "로그아웃 성공"}`
10. **프런트엔드 상태 변경**: 로그인 시 `setUser(userData)`, 로그아웃 시 `setUser(null)`.
11. **화면 출력**: 로그인/회원가입 폼 및 상단 네비게이션 바 사용자 이름 표시.
12. **Langfuse 기록**: `api_request` Root Trace 기록.
13. **실패·예외 처리 및 결함 요약**:
    - **결함 1 (회원가입 HTTP 422)**: [`authClient.ts:24`](file:///c:/myprjs/ai-legal-helper/frontend/src/api/authClient.ts#L24)는 `JSON.stringify({ email, password, name })`을 보내지만 [`auth.py:18`](file:///c:/myprjs/ai-legal-helper/backend/src/ai_legal_helper/api/routes/auth.py#L18)의 `UserCreate`는 `display_name: str`을 요구하여 UI를 통한 회원가입이 100% HTTP 422로 실패한다.
    - **결함 2 (로그인 직후 `user` 상태 오염)**: [`AuthContext.tsx:39-42`](file:///c:/myprjs/ai-legal-helper/frontend/src/context/AuthContext.tsx#L39-L42)는 `apiLogin` 반환값(`{"message": "로그인 성공"}`)을 그대로 `setUser(userData)`에 넣어, 페이지를 새로고침(`F5`)하기 전까지 `user.name`과 `user.display_name`이 모두 `undefined`가 된다.
