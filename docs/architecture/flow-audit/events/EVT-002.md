## 2. End-to-End Sequence Diagram

```mermaid
sequenceDiagram
    autonumber
    participant User as User (Browser)
    participant React as React (AuthContext / Navbar)
    participant FastAPI as FastAPI (auth.py / dependencies.py)
    participant PostgreSQL as PostgreSQL (:5432)
    participant Langfuse as Langfuse (:3001)

    User->>React: 브라우저 접속 (App 마운트)
    React->>FastAPI: GET /api/v1/auth/me (credentials: 'include')
    FastAPI->>Langfuse: create_trace(name="api_request", path="/api/v1/auth/me")
    FastAPI->>FastAPI: Depends(get_current_user) 실행
    alt session_token 쿠키가 존재하는 경우
        FastAPI->>FastAPI: token_hash = sha256(session_token)
        FastAPI->>PostgreSQL: SELECT * FROM user_sessions WHERE token_hash = :hash
        alt 유효한 세션 & 미만료 (expires_at > now)
            FastAPI->>PostgreSQL: SELECT * FROM users WHERE id = :user_id AND status = 'ACTIVE'
            PostgreSQL-->>FastAPI: User 반환
        else 세션 만료 또는 무효
            FastAPI->>PostgreSQL: (만료 시) DELETE FROM user_sessions WHERE id = :id
            FastAPI->>FastAPI: 쿠키 없음 경로(Fallback 검사)로 이동
        end
    end

    alt 유효 세션 없음 & ALLOW_UNAUTHENTICATED_FALLBACK == true (기본값)
        FastAPI->>PostgreSQL: SELECT * FROM users WHERE email = 'tester@local'
        alt tester@local 계정 없음
            FastAPI->>PostgreSQL: INSERT INTO users (email='tester@local', display_name='로컬 테스터')
        end
        FastAPI->>PostgreSQL: UPDATE cases SET user_id = :tester_id WHERE user_id IS NULL
        PostgreSQL-->>FastAPI: 로컬 테스터 User 반환
    else 유효 세션 없음 & ALLOW_UNAUTHENTICATED_FALLBACK == false
        FastAPI-->>React: HTTP 401 Unauthorized {"detail": "로그인이 필요합니다."}
        React->>React: apiFetch가 'auth:unauthorized' 이벤트 발행 -> setUser(null)
    end

    FastAPI-->>React: HTTP 200 OK {id, email, display_name, status}
    React->>React: setUser(currentUser), setLoading(false)
    React-->>User: Navbar에 "로컬 테스터 님" (또는 "⚡ 1인 로컬 테스트 모드") 표시
```
