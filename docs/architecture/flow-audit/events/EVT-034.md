## 2. End-to-End Sequence Diagram

```mermaid
sequenceDiagram
    autonumber
    participant User as User
    participant React as React (EvidenceSection.tsx)
    participant FastAPI as FastAPI (routes/evidence.py:321)
    participant FS as Local File System
    participant PostgreSQL as PostgreSQL (:5432)
    participant Worker as GraphSyncWorker (5초 주기)
    participant Langfuse as Langfuse (:3001)

    User->>React: 증거 문서 카드 우측 '삭제' 버튼 클릭 -> window.confirm() 확인
    React->>React: handleDelete(docId)
    React->>FastAPI: DELETE /api/v1/cases/{case_id}/evidence/{doc_id}
    FastAPI->>Langfuse: create_trace(name="api_request", case_id=case_id)
    FastAPI->>FastAPI: Depends(verify_case_ownership)
    FastAPI->>PostgreSQL: SELECT * FROM evidence_documents WHERE id = :doc_id AND case_id = :case_id
    alt 문서 없음
        FastAPI-->>React: HTTP 404 Not Found
    else 문서 존재
        FastAPI->>FS: os.path.exists(doc.storage_path) 확인 후 os.remove(doc.storage_path)
        FastAPI->>PostgreSQL: 이 문서의 Claim들과 연결된 EvidenceLink(target_type='FACT') 조회
        loop 연결된 각 target_fact_id
            FastAPI->>PostgreSQL: 다른 문서의 Claim이 해당 Fact를 뒷받침하는지 조회
            alt 다른 증거 연결이 없고 Fact.source == 'evidence_promoted' 인 경우
                FastAPI->>PostgreSQL: DELETE FROM facts WHERE id = :fact_id (고아 승격 사실 삭제)
            end
        end
        FastAPI->>PostgreSQL: db.delete(doc) (Cascade로 EvidenceSpan, EvidenceClaim, EvidenceLink 일괄 삭제)
        FastAPI->>PostgreSQL: queue_sync_task(db, case_id) -> INSERT INTO graph_sync_tasks
        FastAPI->>PostgreSQL: db.commit()
        FastAPI-->>React: HTTP 204 No Content
        React->>React: loadEvidences(), loadConflicts(), onEvidenceUpdated() (-> loadCase(caseId))
        React-->>User: 증거 목록에서 문서 제거 및 승격되었던 Fact 카운트 즉시 차감
    end

    Note over PostgreSQL,Worker: 비동기 Outbox 워커 (EVT-010)
    Worker->>PostgreSQL: sync_case_to_graph(db, case_id) -> Neo4j 서브그래프 및 ChromaDB 벡터 재구축
```
