# E2E V6 SC-013 평가 정답지 교정 보고서

- 작성일: 2026-11-15
- 범위: SC-013 1~3차 상담 평가정답, E03 증거 발췌, 테스트셋 생성 스크립트
- 원칙: **평가 정답의 법령 시점 오류를 바로잡되, 실제 증거에 없는 등기 접수일을 생성하지 않는다.**
- 원본 E2E V6 Langfuse Trace는 재작성하지 않음. 과거 PASS는 내부 검증 상태이며, 교정 후 Gold Set에 대한 새로운 법률 정확도 PASS를 의미하지 않음

## 1. 확인된 기존 결함

1. 기존 1차 정답은 2023년 서울 소액임차인 보증금 상한(1억 6,500만 원) 및 우선변제 상한(5,500만 원)을 사건에 바로 적용하여 **최우선변제권을 확정**했다. 하지만 당시 제출된 E01/E02에는 선순위 담보물권 취득일, 주택 인도일, 경매신청등기일이 없다.
2. 기존 2차 정답은 2021년 근저당권이 선순위라고 보지만, E03에는 **2021.03.10 설정계약이라는 등기원인**만 기록되어 있고 **실제 설정등기 접수일**이 없다.
3. 기존 3차 정답은 집행비용→5,500만 원 최우선변제→은행→나머지 보증금 순서를 확정했다. 이 순서는 2021년 담보권자에게 2023년 인상 기준을 일괄 적용해 잘못된 정답을 강제할 수 있다.
4. `scripts/evaluation/create_complex_10cases_testset.py` 안에도 동일한 1~3차 오답이 하드코딩되어 있었다. 정답지 파일만 고치면 재생성 시 복구되는 문제였다.

## 3. 변경된 Gold Set의 평가 방향

**1차**: '2023년 서울 기준에 금액상 해당'과 '선순위 담보권자에 대해서도 실제 최우선변제가 가능한가'를 구별한다. 선행 담보권, 인도, 경매신청등기 확인 전 무조건 5,500만 원 우선변제를 정답으로 강제하지 않는다.

**2차**: 선순위 설정등기와 임차인의 대항요건 시점을 실제로 비교한다. E03의 **등기원인일 ≠ 등기 접수일**을 구분한다. 근저당권이 실제 선순위라는 전제에서 경매로 후순위 임차권 소멸·매수인 비인수와 배당요구종기를 설명한다.

**3차**: 
- 신한은행이 **2021-05-11 이전** 담보물권을 취득한 경우: 2018년 서울 소액임차인 상한 1억 1,000만 원에 보증금 1억 5,000만 원이 해당하지 않아 **해당 담보권자에 대한 최우선변제 불인정**.
- 신한은행이 **2021-05-11 이후 2021년 중** 담보물권을 취득한 경우: 당시 상한 1억 5,000만 원·최대 5,000만 원에 해당할 수 있으나, 인도·주민등록·경매 절차 및 주택가액 제한 등 추가 확인 필요.
- 2023년 기준 최대 5,500만 원을 2021년 담보권자에게 그대로 적용하면 안 된다.
- E06의 2026-06-10 배당요구 접수는 이미 완료된 절차다. 감정가 2억 4천만 원·채권최고액 2억 원은 실제 낙찰가·피담보채권액과 구별한다.

**보류와 오답의 구분**: 필수 증거가 없는 조건부 판단 또는 일부 판단 유보는 자동 실패가 아니다. 반대로 근거 없는 확정적 5,500만 원 우선 배당을 '정답 충족'으로 평가해서도 안 된다.

## 4. 수정 파일

1. `docs/testset/SC-013_선순위근저당_임의경매_최우선변제_배당요구/평가정답_비공개.txt`: 1~3차 기대답변·핵심판정 교정
2. `docs/testset/SC-013_선순위근저당_임의경매_최우선변제_배당요구/증거/2차/E03_부동산등기부등본_을구근저당.txt`: 접수일 미기재 및 등기원인과의 구별만 주석으로 명시
3. `scripts/evaluation/create_complex_10cases_testset.py`: SC-013 원본 기대답변·검증항목·E03 주석 동기화

다른 SC 사건 및 시스템 상담·검색·검증 로직은 수정하지 않았다.

## 5. 후속 검증 및 남은 과제

- 정적 점검: 생성 스크립트 SC-013에 한정된 3개 기대답변·3개 평가항목 교체, 이전 SC-014 이후 코드 불변 확인.
- E2E V6 원본 트레이스: 1~3차 모두 내부 PASS였으나, 새로운 Gold Set 대비 독립 재평가는 아직 수행하지 않았다.
- **미확정 사실**: 실제 근저당권 설정등기 접수일, 주택 인도일, 경매신청등기일, 실제 매각대금·은행 피담보채권 및 다른 우선채권.
- 추후 선후순위를 숫자로 확정하는 회귀 테스트가 필요하면 **테스트용 가상 등기 접수일을 명시적으로 설계한 별도 fixture**로 추가한다. 현 E03을 실제 등록일이 확인된 자료처럼 변경하지 않는다.
- 생성 테스트 및 실제 법률 상담 E2E 전체 재실행은 별도 작업이며, 이 교정만으로 서비스의 법률 판단 오류가 수정되었다고 볼 수 없다.
