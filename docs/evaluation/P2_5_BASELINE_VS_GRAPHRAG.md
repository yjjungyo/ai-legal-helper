# AI Legal Helper — P2.5 Baseline vs. GraphRAG 성능 평가 보고서

## 1. 개요
본 보고서는 `P2_5_BENCHMARK_DATASET.md`의 합성 사건(주택 임대차 분쟁)을 기준으로 기존 문자열 검색(Baseline)과 고도화된 Vector+Graph Hybrid 검색(GraphRAG)의 성능 차이를 정량적, 정성적으로 비교·분석합니다.

## 2. 평가 방법론
- **평가 환경**: `scripts/run_p2_5_benchmark.py` 를 이용한 자동화 벤치마크 테스트.
- **비교 대상**:
  1. `Baseline`: 단순 키워드 포함 여부에 기반한 PostgreSQL / Neo4j 문자열 검색.
  2. `Vector`: ChromaDB를 활용한 의미 기반(Semantic) 검색.
  3. `Hybrid (GraphRAG)`: Vector 검색 결과를 시드로 활용하여 Neo4j의 연관 사실 및 증거(SUPPORTS, CONTRADICTS) 관계를 추적하는 하이브리드 검색.
- **주요 평가 지표**: 상충 진술 탐지, 증거 공백 파악 여부, 무효 증거 필터링 성능, 사건 격리 완전성.

## 3. 테스트 시나리오 및 결과 비교

### 3.1 질문: "보증금을 5월 말에 반환하겠다는 약속 증거가 있나요?"
- **Baseline**: "보증금", "5월", "반환", "약속" 키워드를 단순 포함하는 노드 매칭.
  - *결과*: 일부 텍스트 포함 문서만 찾음 (정확도 낮음). "비밀번호 안 주면 돈 못 줘" 등 의미상 연관 증거를 찾지 못함.
- **Vector**: 질문의 의미적 유사도를 기반으로 검색.
  - *결과*: "5월 말까지 꼭 빼드릴게요", "비밀번호 안 주면 돈 못 줘" 두 증거를 의미상 가깝다고 판단하여 검색함.
- **Hybrid (GraphRAG)**: Vector 매칭을 통해 획득한 시드 노드를 따라 관계성 확장.
  - *결과*: 
    - `[SUPPORTS]` "5월 말까지 꼭 빼드릴게요" → Fact(임대인이 5월 말 보증금 반환 약속)
    - `[CONTRADICTS]` "비밀번호 안 주면 돈 못 줘" → Fact(임대인이 5월 말 보증금 반환 약속)
  - *평가*: **우수**. 질문의 주장을 지지하는 증거뿐 아니라, 반박하는(상충) 증거를 관계망을 통해 한 번에 탐색함.

### 3.2 질문: "관리비 인상과 관련된 증거"
- **Baseline**: "관리비", "인상"이 포함된 Fact("관리비 임의 인상 징수") 노출.
- **Vector**: "관리비 임의 인상 징수" Fact 검출.
- **Hybrid (GraphRAG)**: 해당 Fact와 연결된 `EvidenceClaim` 관계 추적.
  - *결과*: 지지하는 증거가 0건임을 파악. `find_evidence_gaps`를 통해 "관리비 임의 인상 징수" 주장에 대한 *증거 공백(Evidence Gap)*을 명시적으로 반환.
  - *평가*: **우수**. 주장은 있으나 객관적 자료가 없음을 판단.

### 3.3 질문: "퇴거 시 집 상태 사진"
- **검증 목적**: 사용자가 반려(REJECTED) 처리한 증거가 배제되는지 확인.
- **Baseline / Vector**: 노드가 존재하므로 잘못된 근거로 활용될 위험성 내포.
- **Hybrid (GraphRAG)**: 
  - *결과*: 그래프 구축 및 탐색 과정에서 검토 상태(`APPROVED` / `EDITED`) 조건에 의해 필터링되어 관련성 있는 증거로 반환하지 않음.
  - *평가*: **우수**. 데이터 정합성 원칙 완벽 준수.

### 3.4 질문: "누수 문제 증거"
- **검증 목적**: 타 사건(`synth-case-lease-002`) 정보 격리 확인.
- **결과**: 세 검색기 모두 Vector Metadata 필터(`case_id`) 및 Cypher Query(`case_id=$case_id`)에 의해 타 사건의 정보를 노출하지 않음. 격리성 **완전 통과**.

## 4. 장애 복원성 (Fallback) 평가
- **테스트 환경**: 고의로 Neo4j 연결 정보를 조작하거나, 컨테이너 중지.
- **동작**: `GraphRAGRetriever.search_hybrid()` 내부에서 연결 실패 시 Vector 검색 결과만 반환하도록 Fallback 설계.
- **결과**: `available=False` 속성 반환. 시스템 크래시 없이 Vector 검색 결과가 Supervisor로 성공적으로 반환되며 정상 동작. 테스트 코드(`test_api_fallback_returns_unavailable`)에서도 확인됨.

## 5. 결론 및 종합 의견
1. **의미 검색 + 관계성 (Hybrid)의 시너지 확인**: 단순 단어 매칭이나 의미적 거리를 넘어, '무엇이 무엇을 반박하는가'를 구조적으로 추출하는 데 탁월한 성능을 발휘합니다.
2. **환각 및 부정확한 사실의 억제**: 증거 공백을 지적하고, 반려된 AI 추출 결과를 무시함으로써 LLM의 환각을 크게 줄이고 답변의 법률적 신뢰도를 높였습니다.
3. **가용성 보장**: 그래프 DB 장애 시 Vector 저장소를 통한 Fallback 기능을 확보하여, 어떠한 상황에서도 최소한의 의미 기반 검색 서비스를 중단 없이 제공합니다.
