# E2E V7 개선 필요사항

1. **평가 실행 환경 확보(최우선)**: 정상 네트워크와 테스트 데이터 외부 전송 승인을 확보한 뒤 세 시나리오를 재실행. 수용 기준: SC-001 3턴, SC-002/003 각 1턴과 대응계획·문서 결과 및 호출별 사용량 증거 확보.
2. **평가의 임의 기본값 제거**: 기존 V6 평가 스크립트는 누락된 지표·검증 상태에 임의 수치/PASS를 채우는 경로가 있음. 이번 평가에서는 사용하지 않았으며 정식 평가 도구에서도 미측정과 실패를 구분해야 함.
3. **증거 추출 실패 전파**: 첫 시도에서 연결 실패/파싱 실패가 발생해도 다음 증거 등록이 계속됨. 최종 평가 도구는 문서별 추출 결과·승인 사실 수를 점검하고, 실패한 증거를 정상 등록으로 집계하지 않아야 함.
4. **최종 확정 조건**: 정상 E2E 결과, 근거 기반 품질 검토, V5 대비 동등 범위 비교 완료 후 목표시스템을 확정. 현재 증거로 제품 자체의 품질·성능 개선 여부는 판정 불가. 승인 없이 다음 개선 개발 단계로 진행하지 않음.
