# SC-002 인테리어 공사 분쟁 — 데이터셋 관리 안내

기존 SC-008의 사건 설정을 SC-002로 옮기고 통화 녹취록 및 문자 기록을 추가한 독립 평가 자료입니다.

- 01_증거PDF: 사용자 사건 업로드용 PDF 18개
- 02_증거원문TXT: A/B의 동일 정보 조건 입력용 원문 18개 (음성·영상은 텍스트만)
- 03_사건등록: case.json, 상담질문, 타임라인, 인덱스, 단계별 테스트 절차
- 04_평가자전용_업로드금지: 정답지, 평가 방법, 법률 근거 검증 목록

모든 인명·주소·기관·거래·대화는 합성 테스트 데이터이며, 실제 계약·거래·통화·법원 기록이 아닙니다. PDF/TXT 증거 본문에는 이 안내를 넣지 않았습니다. 실제 증빙으로 사용하지 마세요.

평가 원칙: 문서 원문으로 확정할 수 있는 항목과 당사자 주장 및 법률적 판단이 필요한 항목을 분리합니다. 정답지는 분석 모델 입력에 제공하지 마세요.
