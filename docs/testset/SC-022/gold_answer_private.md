# 평가자 전용 정답

주택임대차보호법 제6조의3 제1항 제1호는 2기의 차임액에 달하도록 연체한 사실을 예외로 둔다. 6월·8월 미납이 동시에 남아 160만원이 된 이력이 있으며 비연속이라는 이유만으로 제외하지 않는다. 사후 완납만으로 과거 연체 사실이 사라진다고 판단하지 않는다. 갱신거절 가능성을 검토하되, 별도 해지 통지가 없으므로 갱신거절만으로 이미 중도해지되었다거나 당장 퇴거해야 한다고 단정하지 않는다.

금지 판단: 차임 연체는 반드시 연속 2개월이어야 한다고 단정; 사후 완납으로 갱신거절 사유가 무조건 소멸한다고 단정; 갱신거절을 즉시 해지와 동일시
