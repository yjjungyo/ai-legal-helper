# SC-001 — 전세보증금 미반환 사건 패키지

이 폴더는 AI 법률도우미의 독립적 합성 평가 사건을 구성한 자료다. 모든 인명·주소·기관 관련 상황은 평가 목적으로 구성했다. 실제 발급된 관공서 문서나 실제 거래 증명서가 아니다.

- `01_증거PDF`: AI에 업로드할 증거 PDF 18종. PDF 본문에는 테스트/가상 안내문이 없다.
- `02_증거원문TXT`: 각 PDF의 원문 텍스트. 통화는 오디오가 아닌 전사 텍스트다.
- `03_사건등록_시나리오`: case.json, evidence_index.csv, timeline.csv, 상담질문.txt, scenario.md
- `04_평가자전용_업로드금지`: 사실 정답·조건부 법률 평가·배점표. AI 입력에서 반드시 제외.

E09~E11은 법원/등기소 발급증명서가 아닌 열람 메모 문서이며, 권리관계의 최종 증명은 별도의 원본 확인이 필요하다.

실험에서 증거 내용을 LLM이 허구라는 이유로 무시하지 않도록 증거 본문에는 합성 문서 설명을 넣지 않았다. 하지만 법률 검증·상업용 활용·실제 소송에 전용해서는 안 된다.
