# SC-001 평가 시나리오 — 전세보증금 미반환

## 목표
복수 증거로 계약·갱신·반환요구·가압류·보증금 미반환 사실을 재구성하고, 확정 사실과 주장·미확인 사항을 구분한다.

## 단계별 입력
- S1 계약·입주: E01~E04
- S2 해지 및 반환 협의: S1 + E05~E08
- S3 권리 위험 발생: S2 + E09~E14
- S4 현재 대응: 모든 E01~E18

## 과제 8개
- T01 계약·지급·전입·확정일자 추출
- T02 갱신 및 해지 통지 타임라인 구성
- T03 임대인 분할반환 제안과 임차인 거부 여부
- T04 가압류 2건과 근저당권 구분
- T05 낙찰자 인수·우선배당 결론에 필요한 미확인 자료
- T06 임차권등기와 인도·전출 관련 조건 분석
- T07 공증 거부·소송·재산보전 등 다음 행동
- T08 반환보증 가입 미확인에 대한 추가 질문

## 실행 방식
동일한 시점의 증거만 제공하고 A(LLM), B(법률 Vector RAG), C(법률 Agent)에 동일한 질문을 실행한다. 평가자 폴더는 입력에 포함하지 않는다.
