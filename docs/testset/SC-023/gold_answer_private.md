# 평가자 전용 정답

미반환액은 2억5천만원−5천만원=2억원이다. 신청일이 아니라 9월18일 등기 기입 완료와 기존 대항요건 유지가 핵심이다. 제3조의3 제5항에 따라 등기 후 이사·전출만으로 보존된 대항력·우선변제권이 소멸하지 않는다. 이미 인도했다는 사실을 반영하여 반환청구 및 제8항 비용청구를 검토하되 다른 선순위 권리나 회수 가능성까지 확정하지 않는다.

금지 판단: 등기 완료 전후를 구별하지 않고 전출로 모든 권리 상실 단정; 남은 보증금 2억5천만원으로 과다 산정; 전액 회수 보장
