# KPI 측정 신규 합성 사례 5건

SC-021~025, 사건당 증거 3개·질의 1개·필수 사실 12개. 총 필수 사실 60개, 필수 쟁점 23개.

사건 폴더는 `docs/testset/SC-021/`~`docs/testset/SC-025/`에 각각 배치했다. 이 폴더에는 시험 전 동결한 전체 정답 JSON과 해시만 보존한다. 사건별 `gold.json`은 동일 정답에서 분리한 평가자용 사본이다.

사용자 범위 변경에 따라 최종 보고 대상은 SC-021 한 건이며, 추가 자동 시험·채점 프로세스는 중단했다. 범위 변경 전에 SC-022·SC-023의 실행 산출물이 생성되어 있으나 이번 단독 보고서에는 포함하지 않는다.

평가자 전용 정답은 제품 입력에서 제외한다. 법령 적용 기준은 각 사건 행위 시점이며 공식 출처를 연결했다. Gold는 전문가 확정 전 잠정안이다. 채점은 실제 DB 추출 사실·Planner 반환값·최종 사용자 답변을 구분한다.

LLM Judge 의미매칭에 따른 자동 실측은 전문가 검증을 대체하지 않는다. 추출·상담의 제품 비용과 심사 비용은 분리하고 Langfuse 원본을 보존한다.
