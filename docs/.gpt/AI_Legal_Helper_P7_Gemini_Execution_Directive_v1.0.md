# P7 Gemini Antigravity 실행지시

## 대상 설계
`AI_Legal_Helper_P7_Case_Intelligence_and_Explainability_Design_v1.0.md`


## Gemini 실행 원칙
- Source of Truth 문서를 먼저 읽는다.
- 기존 Repository를 먼저 Audit한다.
- 요구사항을 임의 재정의하지 않는다.
- 기존 구현이 있으면 재사용 우선.
- Material conflict는 `DESIGN CONFLICT`로 보고하고 멈춘다.
- 설계 변경은 `PROPOSED DESIGN CHANGE`로 제출한다.
- 관련 없는 Refactoring 금지.
- 테스트 없는 COMPLETE 금지.
- 실제 Source/Dependency/Framework 선택은 최신성과 Repository 호환성을 확인하고 이유를 기록한다.
- 각 Task는 Inspect → Gap Analysis → Implement → Test → Report 순서로 수행한다.
- 실제 구현 시 Supervisor가 지정한 Task 범위를 넘지 않는다.
