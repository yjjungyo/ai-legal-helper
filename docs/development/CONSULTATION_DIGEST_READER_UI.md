# AI Legal Helper — 상담 결과 '한눈에 보기' UI 개선 (2026-11-01)

## 사용자 화면 문제
긴 답변의 모든 사실/법령/증거/대응안이 동일한 텍스트 강도로 나열되어 사용자가 핵심 판단을 빠르게 찾기 어려움. 특히 조건부 상담은 `presentation`이 없을 수 있어 기존 P2~P5 개편이 적용되지 않을 위험이 있었음.

## 적용 방식
- 상담 답변의 `LEAD` 원문을 '상담 핵심 답변'에 그대로 표시 (임의의 새 법률 판단/요약 생성 금지).
- 명시적 제목이 있는 섹션만 대상으로 '변화', '확인할 사항', '주의' 3종 중 최대 세 영역 구성.
- 각 영역은 **원문 완전한 불릿 두 개 이내**만 노출. 문장 중간 생략, 추론, 재서술, 예외 삭제 금지.
- 소제목과 본문 중요도에 맞는 font-size/spacing 적용, 과도한 증거 태그는 요약 영역에서 시각적으로 간소화.
- **전체 답변은 원래 순서대로** `<details>` 하위에 기본 닫힌 상태로 보존. 펼치면 모든 인용 및 증거 태그 사용 가능.
- `PASS` + 해시와 일치하는 구조화 결과는 기존 P2의 블록을 사용. `CAUTIONARY` 등 구조화 결과가 없을 때에는 프런트엔드 메모리에서 **표시 전용** 블록만 추출. 검증·영속 데이터로 오인하지 않음.
- 명시적 선두 결론도 인식할 수 없는 답변은 임의 요약 대신 기존 본문 렌더러 사용.
- 검증 실패나 WITHHELD 상태에서 허위로 '검증된 결론' 표기하지 않음.

## 범위 제한
이 단계는 *시각적 계층화*이며, 법률적 핵심 결론을 새로 생성하는 상담 요약 엔진이 아니다. 만약 최종 원문에 핵심 결론이 없다면 '한눈에 보기' 역시 확정 결론을 만들어낼 수 없다. 장기적으로는 **답변 생성 시 명시적 `direct_answer / key_facts / action_items / caveats` JSON 작성 → Verification까지 동일하게 검증**하는 후속 개발이 필요.

수동 E2E:
1. 복잡한 임대차 답변: 상담 핵심 → 변화/확인/주의 → 전체 분석 순서 확인
2. 조건부 상담(CAUTIONARY): 새 UI 적용, '검증된 답변' 오표시 금지
3. 일반법 단문 질문: 상세 없이 짧은 결론 우선 표시
4. 단독 인용 `[E01_파일명.pdf]`: 제목 오인 금지
5. 증거 버튼 클릭: 기존 evidenceId/claimId/spanId 그대로 전달
6. 전체 분석 펼침: 답변 원문·파일명·법률근거가 누락되지 않음
7. 모바일 375px / 데스크톱 1440px: 글자 크기, 줄바꿈, 겹침 검토
