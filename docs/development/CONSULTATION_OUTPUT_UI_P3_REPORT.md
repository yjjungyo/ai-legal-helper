# P3 사용자 중심 출력 UI 개선 — 적용 요약 (2026-11-01)

## 적용 범위
- P2 구조화 `presentation.blocks` 화면에 표시, 답변 원문 순서와 문장 유지
- 선두 결론 블록은 강조, 주의·추가 확인·다음 행동은 기본 펼침
- 참고 출처/심층 분석 등 선택적인 섹션만 접기/펼치기 제공 (버튼/ARIA)
- 하단 출처 태그 대량 노출을 `<details>` 근거 목록으로 대체
- 근거 상세에서 정확한 Claim 또는 Span이 있으면 해당 추출 원문을 먼저 노출
- 정확한 근거 위치가 없으면 다른 Claim/Span을 임의 지정하지 않음
- 대화 이력 스크롤 중 진행상태 폴링이 강제로 아래로 이동시키지 않도록 변경
- 데스크톱 대화 폭 860 → 1020px, 모바일 대응

## 변경하지 않는 것
- LLM 생성/Verification/LangGraph/골드셋 평가 로직
- 원본 answer, 검증 상태, 인용 ID 의미, 출처 이름
- 저장/DB 마이그레이션, 외부 추가 API 호출
