# P0-LAW-02 — 개정 법령 시행일 및 적용례 오류 방어

## 장애 재현

질문: 등록 민간임대주택 120세대 운영자가 2026-11-01 체결하는 임대차계약에 2026-10-27 개정 시행령 제36조의 관리비·전기·수도료 신고 항목이 의무적으로 적용되는지 문의.

실제 오답: 2026-10-27을 시행일로 간주하고 2026-11-01 계약에 신설 신고 의무가 적용된다고 답변. 검증 완료로 고객 노출됨.

공식 법령: 대통령령 제36796호 부칙 제1조(원칙적 시행: 공포 후 6개월 경과) 및 제2조(제36조제1항제2호의2·제2호의3: 시행 이후 계약·갱신·변경부터 적용). 제36조의 개정 신고 항목 시행일 2027-04-28. 일부 다른 규정은 2026-10-27부터 시행하므로 법령 전체의 대표 시행일만으로 적용 여부를 판단하면 안 됨.

출처: https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=291499

## 실제 소스 원인

1. `tools/official_statute_search.py`: 공식 법령 목록의 시행일자 1개를 선택된 모든 조문에 복사했음. `조문시행일자` 미사용.
2. 같은 도구가 `lawService.do` 응답의 `부칙단위`를 수집하지 않아 검증·작성 LLM이 적용례를 볼 수 없었음.
3. `agents/verification.py`: 질문 계약일과 조문/부칙 시행일을 교차 비교하는 결정론적 차단 게이트가 없었음. 경량 즉시 PASS 경로도 있었음.
4. `rag/source_schema.py`의 `is_statute_applicable_to_date`가 날짜 누락 시 True를 반환하는 별도 위험이 있음. 이번 1차 조치에서 함수 자체의 호환성은 변경하지 않음.

실제 사용자 Trace가 없는 상태이므로 어떤 LLM 단계에서 최초로 날짜를 잘못 말했는지는 확정하지 않음.

## 변경 범위 — 독립 Draft PR

- `tools/statute_temporal.py`: 부칙공포번호 일치 검사, 개정 부칙 원문 수집, `조문시행일자` 처리, 단순 '공포 후 N개월이 경과한 날' 달력 계산, 명시 예외는 단정하지 않음, 계약 체결일 추출, 검증 답변 적용시점 충돌 탐지.
- `tools/official_statute_search.py`: 조문별 시행일(존재 시) 보존. 계약/개정 날짜 질의에서는 해당 공포번호의 부칙을 표준 Source로 포함하고 메타데이터에 기본 시행일/원문을 제공. 일반 검색 흐름은 보존.
- `agents/verification.py`: 경량 PASS 우회 차단 및 LLM 판정/정책 재승격 이후 시행일 충돌 시 REVISE 강제.
- `tests/unit/test_statute_temporal_p0_law_02.py`: 이번 질문의 잘못된/올바른 답변, 공포 후 6개월, 부칙 시행일 예외, 공포번호 일치, 계약일 vs 공포일, 부칙 누락시 PASS 방어.

## 검증 미완료 항목 및 운영 반영 전 필수 확인

1. 로컬 개발 환경에서 pytest 실행: `cd backend; python -m pytest -q tests/unit/test_statute_temporal_p0_law_02.py tests/unit/test_official_statute_search.py tests/unit/test_p1_defects_reproduction.py`
2. 실제 국가법령정보 API 연결 응답에서 `부칙단위`, `부칙공포번호`, `부칙내용`, `조문시행일자` 구조 확인. XML 버전에 따라 원문 경로가 다른 경우 파서 보완.
3. 두 기준일(2026-11-01, 2027-04-28)에 신규 계약 질문을 실행하여 각각 미적용/적용(다른 요건 충족 전제) 구별 검증.
4. 같은 공포번호라도 조문별 예외가 있으면 기본 시행일을 무조건 적용하지 않도록 더 엄밀한 조문단위 메타데이터 설계 필요.
5. 최종 answer 검증 게이트: 일반 상담 `finalize_node`에서 문장 재조합 이후 새로 생긴 주장을 재검증하는 별도 단계가 아직 필요.
6. 조문/부칙 조회 실패·원문 부재·날짜 계산 불능은 사용자에게 '시행일 확인 불가'로 전달하고 검증 완료로 표시하지 않을 것.
7. 기존 일반 법률 질문·SC-001 Gold Set·HILT 승인·프런트 출처 렌더링 회귀 테스트.

## 주의

이번 PR은 오류 차단을 위한 소규모 수정 초안이며 테스트는 아직 실제 개발 환경에서 실행하지 않았음. 기존 main에는 병합하지 않았고, 실서비스 품질 개선이 완료됐다고 판단하지 않음.
